# Phase B day 2

Tuesday, October 27, 2026.

A page, post, glossary term, city, and property type now has a rich text body. The body can include an H2. The H1 stays in the SEO fields.

A record stays a draft until it has a title, an H1, and a body. Publishing without those shows that message on the missing fields. A glossary term uses its term as the title and its definition as the body.

A blog post also has a publish date and an author. The publish date is filled when the post is published and the date is empty. A post cannot be published without an author.

A draft is hidden from a signed-out visitor and from a moderator. A content manager and the owner can open it.

Saving a slug that another page, post, term, city, or property type already uses shows: “This URL is already used by a page.” The same check names a post, a glossary term, a city, or a property type.

The homepage lock for the build is in `docs/phase-b-homepage.md`.
