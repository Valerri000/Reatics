# Billing state lock

Wednesday, November 25, 2026.

Use the Phase C unavailable page. Do not add a second removed-listing page. The page says "This listing is no longer available." It is noindex. The listing URL stays.

Broker-facing states:

- Active. Listings stay in search, on the map, and on the public page.
- Past due. Listings stay visible while payment retries continue.
- Canceled. Listings leave search, the map, the broker page, and the sitemap. The listing address still opens.

Desktop uses three columns. Phone uses one column.

A comped account stays visible. Coworking listings stay visible when the subscription is canceled. They hide when the listing is unpublished or when verification is revoked.

A past due subscription stores a grace notice in the mailbox. The notice is not sent.
