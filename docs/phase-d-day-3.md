# Phase D day 3

Wednesday, November 25, 2026.

An account stores the subscription status: active, past due, canceled, and comped. A broker, an owner with listings, and a broker and owner use this status. An owner admin can set it. A content manager cannot.

When the status is canceled, that account's listings leave search, the map, the broker's public page, and the sitemap. The listing URL stays. The page says "This listing is no longer available." It is noindex. It is the Phase C unavailable page.

When the subscription is active again, the listing returns on that same URL.

A past due account stays visible. A comped account stays visible.

Coworking listings stay visible when the subscription is canceled. They hide when the listing is unpublished or when verification is revoked.

A grace notice is stored in the mailbox when the subscription is past due. It is not sent.

The broker-facing states are active, past due, and canceled, on desktop and phone.
