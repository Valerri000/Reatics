# Sitemap

Tuesday, November 3, 2026.

`/sitemap.xml` lists a record when that record is published, set to index, and checked for the sitemap. A page, a post, a glossary term, a city, and a property type are covered. A draft stays out. A noindex record stays out. A record whose sitemap box is unchecked stays out.

Terms and Privacy stay out while they are unpublished. After the copy is published, set to index, and checked, that page is listed.

The public listing page is not in this phase, so listings are not listed.

The file shows at https://18.118.84.127/sitemap.xml after this revision is built on that host.
