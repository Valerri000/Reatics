# Phase C day 2

Tuesday, November 10, 2026.

The listing page is `/listings/{slug}` from the listing record. The response includes the title, the H1, the price, the address, and the description. The browser title, meta description, canonical URL, and index or noindex come from that listing's SEO fields.

The page shows the photo, thumbnails, one transaction label, the facts row, availabilities, and the description. A broker listing shows the broker block. A coworking listing shows 1-888-518-9168 and does not show the provider contact details.

A report stores the name, email, error type, and description, then confirms the report. The staff queue that works those reports is Phase D.

A listing that is no longer available stays on the same URL, says "This listing is no longer available," is noindex, and is left off the map and the sitemap.
