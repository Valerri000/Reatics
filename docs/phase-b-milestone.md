# Phase B milestone

Friday, November 6, 2026.

Checked against this revision. The pages show on https://18.118.84.127 after this revision is built on that host.

- Homepage, About, Services, Contact, Scholarship, and Steps to Renting are public pages.
- Blog index and posts support drafts, a publish date, an author, and preview.
- Glossary index and terms are public.
- Glendale is a city record on the shared city template. Office is a property-type record on the shared property-type template.
- Another city or property type is a new admin record, using the same template.
- Title, H1, and body are required before publish, and they are in the first response.
- SEO fields set the browser title, meta description, canonical URL, and index or noindex.
- The sitemap lists only published, indexable records that are checked for it.
- Changing a slug returns a 301, and an editor can add a redirect by hand.
- A content manager can publish a page without a developer.
- Terms and Privacy are published when the copy has been supplied. Until then they stay unpublished and noindex.
