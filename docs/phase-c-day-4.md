# Phase C day 4

Thursday, November 12. The map filters update the listings as they are chosen. Clear all removes the filters and the drawn area.

The launch filters are sale, lease, or coworking; property type; price; square footage; keywords; and state, city, county, or ZIP. The property type list changes with that choice. Sale uses office, retail, industrial/flex, land, medical, shopping center, multi-family, and other. Lease uses office, retail, industrial, flex, medical, and land. Coworking uses desk counts 1–2, 3–4, 5–10, 11–20, and 25+.

Lot size, cap rate, year built, units, and listing ID stay on the listing record. They are not filters.

A drawn search area keeps the stored points inside it. Clear area removes that shape. Changing a filter updates the cards and the pins. It does not reload the map from scratch.
