A visitor who opens an old address receives the stored redirect. A page, a post, a glossary term, a city, and a property type are covered. A redirect added by hand answers the same way. The usual answer is a 301. A row saved as 302 stays a 302.

When a slug changes again, the older redirect points at the newest address. Two redirects that point at each other do not answer.

The admin, the API, health, and static files are left alone. A content manager can add a redirect. A space seeker cannot.

These answers show on https://18.118.84.127 after this revision is built on that host.
